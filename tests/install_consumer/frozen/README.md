# 冻结消费者规则

D0.02 当前不存在上一正式 SDK；不得把“无历史基准”计作兼容测试成功。`../baseline` 是版本元数据的 0.x 开发安装对照，不是冻结正式消费者。

D1 起对实际公开头和组件建立独立安装消费者。首个正式发布保存消费工程、测试、工具链/CRT 配置和来源摘要为不可变基准；后续仅把旧工程指向新安装树，重新配置/编译/链接/运行，不与 SDK 同步修改旧调用去适配破坏。

新增受支持基准用新目录及版本，旧目录保留。公开表面变更先审查 manifest/声明/语义，再以冻结消费者验证；三者不能互相替代。首发正式基准建立与最终兼容矩阵由 D8.01/D8.06 验证。
