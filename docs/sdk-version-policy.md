# SDK 版本与公开契约演进政策

工作包：D0.02；依据 A19.2–A19.4。本政策沿用已批准架构，不改变 wire、Operation 或持久格式。

- 当前开发版本：`0.1.0-dev.1`。SDK 使用独立 SemVer；文档 v3.3 不代表 SDK 发布版本。
- 0.x 阶段公开变更仍同步 ADR、合同、清单和测试，但没有尚未发布的永久兼容承诺。正式 1.0 只冻结 Stable 范围及兼容规则，不禁止新增经评审公开头。
- stable 为正式源码兼容承诺；experimental 明示风险；detail 为内部实现。Stable 示例不能必须依赖 experimental/detail 才能工作。
- Patch 只作兼容修复；Minor 用于验证过的兼容扩展、弃用和说明；Major 用于不兼容源码或契约调整。新增重载/默认参数/模板约束/noexcept/所有权/线程契约/PUBLIC 选项仍必须评估，不假定“只新增”必兼容。
- 弃用至少在一个已发布 Minor 中给出替代与说明，仅在后续 Major 移除。紧急安全调整也需明确版本和公告。
- 主要承诺是旧源码不修改地重新编译、链接、运行；没有专项 ABI 范围、固定编译器/CRT 条件和测试时，不承诺替换任意既有二进制。

三层门禁独立：公开表面清单与 diff；关键声明/行为审查；冻结消费者在新安装树的实际构建运行。不能用头文件名/hash 或文本 diff 代替后两层。公开变更先形成具体差异并审查，再更新清单；禁止自动覆盖 golden 迎合实现。

当前首发前不存在上一正式 SDK，冻结消费者层记“无历史正式基准”，不计 Passed。D0.02 的版本元数据安装程序只是开发对照；D1/D8 建立真实消费者，首个正式发布时保存不可变消费工程及测试。

SDK、Operation、类型/codec、Plan wire、RPC、catalog docs、canonical 与持久格式分别版本化。同版 Operation 语义不可原地改；SDK 版本变更不能授权修改 canonical 字节或持久含义。稳定身份可以持久化，registry handle、指针、锁和运行栈不可当 ABI 或持久数据。

当前报告 C++20/MSVC x64 合同基线；D0.06 锁定编译器、CRT、expected 后端和依赖选项，D8 才签核最终支持矩阵。该政策不引入旧项目 API 或数据迁移。
