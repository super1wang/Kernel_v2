# GUI 为主人工前端，DSL 可选

任务 D0.02，来源 A23.1；状态：沿用已批准架构决定，当前落地产物待 D0.02 评审。

## 决定

桌面产品以 GUI 为主人工前端；CLI、结构化 Plan、Client SDK 是稳定自动化面。人类 DSL/REPL 可选，若实现必须编译到同一 Plan，不能另造解释器。

## 验证与影响

D0.02 反例阻止将 DSL 加为首发必需组件；DSL 缺失不阻 G0/G8。本阶段不开发 GUI 产品，这一决定只约束未来消费者。

业务、权限和事务仍由内核既有 Operation/Outcome/Plan 合同负责；不增加新产品模块、版本门禁或第二 Runtime。
