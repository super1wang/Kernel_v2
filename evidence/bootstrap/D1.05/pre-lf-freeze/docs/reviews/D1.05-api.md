## 规格与可实现性结论

| 约束 | 已冻结的实现边界与必要验证 |
|---|---|
| 一份业务定义、真正 typed 分派 | 注册模板固化 A/R/F/Reader thunk；Catalog 私有桥在原身份、世代、slot、原快照与 token 重验后调用。candidate_read 普通分支只调用原 pair.first。必须有真实结果/业务计数及私有提取编译负例，不能以另一演示函数代替。 |
| 实际参数与目标 | 每次 validate 与可信冻结 TargetProjection 都执行，核对完整有界目标集合；空、重复、超容、另一实参目标拒绝。projection 非空且不是请求参数。Reader 服务合同须关联实际目标，使用不同目标不同数据验证。可信 native 模块不是恶意代码沙箱。 |
| 真正授权治理 | Policy 每次使用当前同一短仲裁重验原 Caller/Target、会话/Store、期限、世代、目标实例与完整权限 tuple；Catalog 权限与安装 Policy 集合精确相等。缓存绑定不能复活撤权材料，不能跨规则拼权限。准入线性化后的 Read 与 Effect 消费明确分开。 |
| 可信线程 | 可信装配端口按实际线程身份固定映射，每次查验角色/affinity；请求无强制 inline/block 参数。不支持的阻塞包装用编译拒绝验证，已有线程准入用真实其他线程运行验证。 |
| Provider 与资源不可用 | 有效不可用 shape/资源操作可以 bind，但不建立 Read 授权；invoke 按确定优先级返回 ProviderUnavailable/ResourceUnavailable，业务零进入。仅支持且无资源声明的 Read 才 resolve/prepare_inline，因而运行拒绝路径可达。 |
| 资源合同衔接 | Registry slot owner 仍只是注册寿命；没有被冒充为本次 ResourceLease。Native 成功固定场景明确空 granted_resources。CoreContracts 非空借用构造只作独立受信 lease 寿命合同验证，不宣称 Native 资源获取或 D3 调度已实现。 |
| 所有权、配额和异常 | shared owner 拒绝空控制块；双层槽分别 RAII、有限、不等待/扩容。原 owner 持续到调用及结果处理结束；锁内不执行任意回调/最后析构。异常后恢复容量，取消/预算/服务器期限进入前判定。 |
| 输出与真实事实 | 进入前 Rejected；进入后业务错误、异常、无效 R 都形成有证明的 FailedBeforeApply，不能再返回入口拒绝。失败分支无 R，避免递归调用抛异常的验证器。成功用经校验的真实空事实，不发行 Task/Commit/Effect 身份。 |
| CoreContracts 增量 | 借用模式 optional 拥有容器保持 disengaged，避免 Debug 隐藏代理分配；原拥有构造保持。Outcome 九分支只把临时 unresolved 容器换成无分配 count/成员判断，并保留集合等价、重复、引用及 Resolution 语义；要求全合同回归，不能只验 Read。 |
